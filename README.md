# Ayu for Zen

Ayu color themes for [Zen Browser](https://zen-browser.app/), packaged as a Zen Mod and compatible with [Sine](https://github.com/CosmoCreeper/Sine).

## Variants

Four variants, ordered from lightest to darkest:

1. **Light (Default):** A clean, bright color scheme.
2. **Mirage:** A softer dark theme with a blue-gray background.
3. **Dark:** The classic Ayu dark palette.
4. **Evolve:** A near-black variation of Ayu Dark.

The palettes are based on Ayu, with color adjustments to better match the original color scheme, particularly the orange tones in Dark and Evolve.

## Installation

1. Install [Sine](https://github.com/CosmoCreeper/Sine).
2. Open **Zen Settings > Sine Mods**.
3. Paste this repository's URL into the installation field.
4. Install and enable the mod.

## Configuration

The default variant is **Ayu Light**.

To switch themes, open the mod's settings and select a variant from the **Variant** dropdown.
